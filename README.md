# Kamera timelapse — nyilvános alkalmazásismertető

A személyes Kamera timelapse Home Assistant-alkalmazás nyilvános kezdőlapja
és adatkezelési tájékoztatója a Google OAuth Branding beállításaihoz.

Ez a tárhely kizárólag statikus ismertető fájlokat tartalmaz.
Kamerafelvétel, Home Assistant-konfiguráció, helyi hálózati cím vagy hitelesítő adat nem kerül ide.

- index.html: alkalmazásismertető, működés és hivatkozás az adatvédelemre.
- privacy.html: az alkalmazás tényleges adatkezelése és a hozzáférés visszavonása.
- style.css: közös, külső függőség nélküli, reszponzív megjelenés.
- .nojekyll: közvetlen statikus GitHub Pages-kiszolgálás.

Üzemeltető: a M3NT1 GitHub-fiók tulajdonosa.
